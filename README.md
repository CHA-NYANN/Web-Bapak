# Album ulang tahun Pak Hanny
Buka index.html di browser. Foto dan tampilan tersimpan lokal.

Folder asset berisi foto sumber. Folder album berisi versi WebP yang sudah disesuaikan orientasi dan ukurannya. photos.js menyimpan urutan foto dan keterangan tiap bab. Nama dasar setiap foto sama dengan sumbernya.

Album memuat 14 foto almet biru dan pencapaian, 15 foto di lab, serta 18 foto di luar lab. Foto 1000093267 sama dengan 1000091144. Foto keluarga lama 1000265991 dipajang di pigura di atas kotatsu. Di taman, 14 foto kelulusan melintas otomatis satu per satu.

Tiga foto baru masuk album: DSC_0014 (berdua Pak Hanny seusai wisuda, masuk bab kelulusan) serta 1f4b28e1-34ad-4dee-89ae-8ff6d6be48ec dan 7811c41c-0dd7-48e7-8c7c-56f7b59f985b (momen ulang tahun Pak Hanny dirayakan satu lab, masuk bab lab/kamera).

Bagian video di akhir halaman diputar lewat Google Drive (embed iframe), bukan file lokal. Setelah videonya diunggah ke Drive: bagikan dengan akses "Siapa saja yang memiliki link", ambil ID file dari URL-nya (bagian antara /d/ dan /view), lalu isikan ke konstanta DRIVE_VIDEO_ID di script.js. Selama ID itu kosong, otomatis tampil pesan cadangan "Video ucapan kami sedang disiapkan, Pak."

night.js, edo.css, press.css, dan styles.css adalah sisa draf lama (tidak di-link dari index.html, sudah digantikan tsuki.js/journey.css/jamuan.css). Aman dihapus kapan saja, dibiarkan dulu untuk jaga-jaga.
